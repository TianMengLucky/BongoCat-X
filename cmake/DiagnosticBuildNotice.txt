BongoCat host without a bundled Live2D renderer

This host was built without the Cubism SDK. Live2D becomes available after
installing a compatible Live2D renderer plugin and supplying Cubism Core
through the existing live2d import. Inochi2D is supported by the separately
built Inox2D plugin and does not require Cubism Core.

Manage renderer plugins on the Plugins page in preferences. Model content
selects the renderer automatically. Missing plugins are reported during
model import/load; the bundled Live2D preview uses a diagnostic fallback.
