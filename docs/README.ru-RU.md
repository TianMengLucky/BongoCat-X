## 🛠️ Сборка из исходного кода

BongoCat требует CMake 3.24 или новее, компиляторы C11 и C++17, файлы разработки OpenGL и инструменты Rust (cargo через rustup). Corrosion собирает модули Rust. При настройке по умолчанию загружаются SDL3, stb, miniaudio, Nuklear и Corrosion; первая сборка требует доступа к сети.

Выполните следующие команды в корневом каталоге проекта (каталоге, содержащем `CMakeLists.txt`).

### 📋 Предварительные требования по платформам

- **Windows:** Visual Studio 2022 (с рабочей нагрузкой «Разработка классических приложений на C++») и CMake. Используйте генератор MSVC; MinGW может собрать диагностический бэкенд, но не поддерживает Cubism SDK.
- **macOS:** Xcode Command Line Tools, CMake и Ninja. Если целевая архитектура отличается от архитектуры хоста по умолчанию, укажите её через `CMAKE_OSX_ARCHITECTURES`.
- **Linux (Debian/Ubuntu):** GCC или Clang, Ninja, а также заголовочные файлы OpenGL/X11:

  ```bash
  sudo apt-get update
  sudo apt-get install -y build-essential cmake ninja-build \
    libgl1-mesa-dev libx11-dev libxi-dev libxfixes-dev libxcb-screensaver0-dev libfontconfig1-dev fonts-noto-cjk
  ```

### 🔧 Настройка и сборка

В Linux и macOS используйте генератор с одной конфигурацией, например Ninja:

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DBONGO_CAT_FETCH_DEPS=ON
cmake --build build --parallel
```

В Windows выполняйте команды из командной строки разработчика Visual Studio 2022 (или любой другой оболочки, где доступен MSVC):

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 `
  -DBONGO_CAT_FETCH_DEPS=ON
cmake --build build --config Release --parallel
```

Исполняемый файл находится в `build/BongoCat` в Linux, в `build/BongoCat.app/Contents/MacOS/BongoCat` в macOS и в `build/Release/BongoCat.exe` для сборок Visual Studio в Windows.

### 🧪 Тестирование

Тестовые цели по умолчанию отключены для ускорения обычной сборки. При необходимости включите и соберите их:

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Для генератора с несколькими конфигурациями, такого как Visual Studio, явно укажите конфигурацию сборки:

```powershell
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

### 🎭 Live2D / Cubism SDK (необязателен — сборка возможна и без него)

Проприетарный Cubism SDK остаётся необязательным. Без него собираются приложение и плагин Inox2D. Совместимый плагин Live2D и отдельно предоставленный Cubism Core включают Live2D без пересборки приложения. SDK нужен для сборки отдельного плагина C++.

1. Откройте [страницу загрузки Cubism SDK](https://www.live2d.com/en/sdk/download/native/), примите условия Live2D Proprietary Software License Agreement и скачайте **Cubism SDK for Native** (релизы собираются и тестируются с SDK `5-r.5`).
2. Распакуйте архив. Если распакованная папка называется `CubismSdkForNative-5-r.5`, переименуйте её в `CubismSdkForNative` и поместите в `vendor/` так, чтобы дерево содержало `Core/` и `Framework/`.
3. В новых архивах SDK больше нет GLEW. Скачайте [GLEW 2.2.0](https://github.com/nigels-com/glew/releases/download/glew-2.2.0/glew-2.2.0.zip) и распакуйте в `vendor/CubismSdkForNative/Samples/OpenGL/thirdParty/glew` (каталог, напрямую содержащий `include/GL/glew.h` и `src/glew.c`).

Также можно хранить SDK в любом месте и явно передать его путь:

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DBONGO_CAT_CUBISM_SDK=/path/to/CubismSdkForNative
```

SDK должен включать библиотеку Core, исходный код Framework и каталог сторонних библиотек OpenGL GLEW в структуре, ожидаемой `cmake/Cubism.cmake`. Сборки Cubism в Windows требуют Visual Studio 2022. Когда SDK размещён, обычная конфигурация даёт сборку с рендерингом Live2D; `BONGO_CAT_REQUIRE_CUBISM=ON` теперь только завершает конфигурацию ошибкой с инструкцией по импорту, если SDK отсутствует (используется в release CI). Если это не нужно, оставьте значение по умолчанию `OFF`.

### ⚙️ Параметры CMake

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `BONGO_CAT_FETCH_DEPS` | `ON` | Загружает сторонние зависимости фиксированных версий через `FetchContent` CMake (включая Corrosion и зависимости Rust-крейта). Установите `OFF`, только если SDL3, stb, miniaudio, Nuklear и Corrosion уже доступны для CMake. |
| `BONGO_CAT_CUBISM_SDK` | `vendor/CubismSdkForNative` | Путь к Cubism SDK for Native. |
| `BONGO_CAT_REQUIRE_CUBISM` | `OFF` | Определяет, приводит ли отсутствие SDK к ошибке конфигурации. По умолчанию `OFF`: без SDK собирается диагностический бэкенд без рендеринга Live2D; установите `ON`, чтобы требовать SDK (используется в release CI). |
| `BONGO_CAT_WARNINGS_AS_ERRORS` | `OFF` | Обрабатывает предупреждения нативного компилятора как ошибки. |

Для автономной сборки установите `BONGO_CAT_FETCH_DEPS=OFF` и предоставьте конфигурации пакетов CMake для SDL3 (включая `SDL3-static`) ; если stb, Nuklear и miniaudio не могут быть найдены автоматически, укажите также их каталоги включения:

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DBONGO_CAT_FETCH_DEPS=OFF \
  -DBONGO_CAT_STB_INCLUDE_DIR=/path/to/stb \
  -DBONGO_CAT_NUKLEAR_INCLUDE_DIR=/path/to/nuklear \
  -DBONGO_CAT_MINIAUDIO_INCLUDE_DIR=/path/to/miniaudio
```

## 🧭 Техническая архитектура

Приложение C11 использует SDL3 для событий, обновления моделей и вывода в главном потоке, а Nuklear — для настроек. `src/rust/bongo-safe` управляет разбором недоверенных данных, очередями и метриками ввода и общим состоянием рабочих потоков плагинов. Мост Live2D, бэкенд ресурсов Vulkan и адаптеры Windows COM/WIC используют C++17.

Платформенные обработчики передают события клавиш и кнопок мыши в ограниченную очередь Rust, отдельно объединяют движения указателя и пробуждают главный поток для обновления параметров моделей и интерфейса. Версионированный C ABI загружает плагины Live2D/Inox2D с OpenGL, Vulkan или Metal на поддерживаемых платформах.

Совместимость и сборка: [Плагины рендеринга](model-plugins.md). Ограничения бэкендов и объём проверок: [Нативный рендеринг](live2d-vulkan-metal.md).

## ❓ Часто задаваемые вопросы

### 🔒 Записывает ли BongoCat мой ввод с клавиатуры или мыши?

BongoCat обрабатывает ввод локально для анимаций и сочетаний клавиш и не отправляет данные ввода или использования. Включённый плагин статистики может локально сохранять суммы, дневные/часовые графики и время активных приложений. Текст, порядок клавиш, заголовки окон, URL и координаты не сохраняются. На странице статистики можно отключить сбор, сбросить или экспортировать историю. См. [Плагин статистики](statistics-plugin.md). Проверка обновлений запрашивает общедоступные метаданные выпусков.

### 🖼️ Каков прогресс поддержки Vulkan / Metal?

Настройки → Приложение → Бэкенд рендеринга переключает API без перезапуска: OpenGL ↔ Vulkan на Windows / Linux x64, OpenGL ↔ Metal на macOS. Системный вариант использует OpenGL. Подключены загрузка нативных текстур, отрисовка Cubism, чтение GPU и перезагрузка модели; модель и выбранные движения/выражения сохраняются. Ошибка инициализации или загрузки возвращает OpenGL. Vulkan/Metal экспериментальны: слои клавиш/эффектов/указателя теперь поддерживают все бэкенды. Live2D поддерживает динамическое разрешение в OpenGL, Vulkan и Metal: декодирование и масштабирование в фоне, синхронная загрузка в нативную GPU. Отключение перезагружает текстуры с выбранным качеством. Нативные бэкенды кэшируют фон стола, учитывают его в границах окна и скругляют четыре угла на GPU без дополнительной полноэкранной текстуры. Слои используют программную отрисовку SDL, кэшируются до изменения ввода, затем смешиваются с готовым нативным кадром и загружаются в GPU; производительность пока не измерена.

Оптимизация рендеринга доступна для Vulkan / Metal и по умолчанию выключена. Vulkan предлагает три параметра, Metal — только крупные выделения памяти. Inox2D Metal объединяет вершины кадра; для Live2D Metal этот параметр недоступен. Три подопции сохраняются отдельно; изменения перезагружают модель. Inox2D Vulkan поддерживает параллельную запись и крупные блоки памяти. Live2D Vulkan поддерживает VMA и параллельную запись при обычном смешивании, без внеэкранных узлов и высокоточных масок. Live2D использует вторичные буферы при 128 Drawable и до четырёх потоков при 128 снимках объектов для отрисовки; остальные модели сохраняют последовательный путь SDK. Live2D Vulkan Bindless использует таблицу до 64 текстур атласа при обычном смешивании без внеэкранных узлов; при недостатке возможностей устройства или ёмкости сохраняется прежний путь. Inox2D Bindless не реализован. Крупные пулы могут потреблять больше памяти; прирост производительности ещё не измерен.

Сборки с SDK включают `BONGO_CAT_CUBISM_VULKAN=ON` на Windows / Linux x64 (`glslangValidator` или `glslang`, пакет Linux `glslang-tools`; при запуске Vulkan 1.3) и `BONGO_CAT_CUBISM_METAL=ON` на macOS (инструменты Metal из Xcode). Для отключения используйте `OFF`. Metal и `.metallib` включаются только в macOS, Vulkan и `.spv` — только в Windows / Linux x64, вместе с вариантами смешивания. Диагностические сборки без SDK не включают эти ресурсы Live2D. GitHub Actions готовит инструменты и проверяет ресурсы для каждой платформы. Выполнены статические проверки; сборка и GPU ещё не проверены. См. [интеграцию и проверку](live2d-vulkan-metal.md).

### Вид меню параметров

Настройки используют сворачиваемые карточки групп. Окно, Модель, Приложение и Оформление по умолчанию развёрнуты. Компактный интерфейс в разделе Оформление уменьшает интервалы, сохраняя описания. Параметр сохраняется автоматически.

### Плагин статистики ввода

Плагин Rust собирается вместе с приложением по умолчанию. Его можно включить, отключить или импортировать на странице плагинов. Страница статистики показывает счётчики клавиатуры и мыши, графики по дням и часам, локальное хранение и экспорт CSV. См. [Плагин статистики](statistics-plugin.md). Время активных приложений включает рейтинг, почасовые итоги и отдельный переключатель. Сбор, сохранение и экспорт выполняются в отдельном потоке. Плагин добавляет пункт статистики при включении и убирает его при отключении или удалении.

На странице статистики можно сохранить или сбросить названия единиц и множители движения и прокрутки. Настройки оформления используют общую палитру основного, дополнительного, текстового цветов и фона страницы.

### Динамические плагины рендеринга

Настройки → Плагины позволяют устанавливать, включать и удалять локальные движки рендеринга. Перед изменением активного плагина переключитесь на другой движок. Live2D использует плагин на C++, а Inochi2D — Rust-плагин Inox2D с OpenGL, Vulkan (Windows/Linux) и Metal (macOS), без wgpu. При импорте сначала определяется содержимое модели (`.model3.json`, `.inp`, `.inx`). Весь JSON читается и записывается в Rust.

Портативные версии Windows распространяются в ZIP-архивах. Сохраните распакованную папку `plugins` рядом с исполняемым файлом. Подробнее об упаковке, зависимостях для автономной сборки, ABI, привязках параметров и ограничениях совместимости: [Плагины рендеринга](model-plugins.md).

Каждый push в `dev`, изменяющий код, ресурсы или конфигурацию сборки, публикует предварительный выпуск GitHub. Изменения только документации пропускаются; запуска по расписанию нет. Все платформы собирают отправленный коммит. Последний стабильный выпуск не заменяется.

Ночные предварительные сборки используют одну [страницу nightly](https://github.com/TianMengLucky/BongoCat-X/releases/tag/nightly), обновляют тег и заменяют файлы с постоянными именами. При сбое сборки платформы сохраняются предыдущие файлы.

### Linux Wayland / evdev

Экспериментальный ввод evdev в Linux Wayland включается через `BONGOCAT_ENABLE_EVDEV=1`. Сначала устройства открываются обычным пользователем только для чтения. При отказе защищённая установка запрашивает аутентификацию через `/usr/bin/sudo`, открывает устройства, немедленно сбрасывает привилегии и перезапускается до инициализации SDL, настроек и моделей. Программа, sudo и родительские каталоги должны принадлежать root и запрещать запись группе и другим пользователям. Для сборок разработки и переносных установок доступ настраивает администратор отдельно. Путь sudo задаётся через `BONGO_CAT_SUDO_EXECUTABLE`. Ошибка останавливает запуск; постоянные права не меняются. Отслеживаются только устройства, присутствующие при запуске; подключение новых требует перезапуска. Не запускайте напрямую от root и не вступайте в группу `input`. Ввод может содержать пароли; блокировка экрана, смена сеанса и скрытие питомца не останавливают наблюдение.

[SECURITY.md](../SECURITY.md#linux-input)

В настройках окна можно выбрать свой фон: PNG, JPEG, WebP, BMP или GIF (первый кадр). Изображение заполняет окно по центру с сохранением пропорций; оно и одноцветный фон взаимно исключают друг друга. Копия хранится в каталоге данных приложения и доступна после перемещения оригинала. Ограничения: 64 МБ и 16 мегапикселей. Поддерживаются OpenGL, Vulkan и Metal.

Live2D автоматически повторно использует буферы геометрии и повторяющиеся состояния рендеринга. Потоковая загрузка OpenGL, пакетная загрузка и кеш конвейеров Vulkan, общие буферы Metal и адаптивные нативные маски не требуют отдельного переключателя. Производительность и поведение на платформах ещё предстоит измерить.

Vulkan автоматически управляет памятью: Live2D использует блоки VMA по 1 MiB по умолчанию или 16 MiB при включении крупных выделений. Послойное представление Windows сохраняет одну цветовую цель. При скрытии или сворачивании окна кеши чтения освобождаются после завершения работы GPU и создаются заново по необходимости. Качество и динамическое разрешение настраиваются отдельно.

Настройки → Питомец → Диапазон мыши: горизонталь/вертикаль 25–400%, по умолчанию выключен; 100% без изменений. Нарисованные лапы Mver двигаются дальше; Live2D сохраняет границы модели. Взгляд и окно не меняются

### Несколько клавиш и читаемые символы в зеркальном режиме

Mver (OpenGL/Vulkan/Metal) отдельно обрезает руку, рамку и символы, соединяя нажатые клавиши знаком + в одном пузырьке. Рамка и хвостик отражаются вместе с моделью; символы остаются читаемыми и в режиме одной клавиши. Настройте три области, интервал вокруг + и лимит для каждой стороны в `hand-layout.json` рядом с изображениями рук; после изменений перезапустите приложение. См. [инструкцию и пример](hand-layout.md).

Окно действий проверяет ссылку `Sound` и наличие файла, показывая отдельный регулятор рядом с движениями со звуком. Настройте 0–100% перетаскиванием или вводом; двойной щелчок возвращает 100%, а 0% отключает звук. Значения сохраняются для каждой модели и движения и применяются в окне, сочетаниях клавиш, случайных движениях и контекстном меню, также во время воспроизведения. Другие движения с тем же файлом сохраняют свою громкость.

### Плагин предметов

Независимый плагин предметов включён по умолчанию. Включите его в Настройки → Плагины, чтобы открыть страницу предметов. Поддерживает импорт нескольких изображений и перетаскивание, положение, размер, поворот, непрозрачность, передние/задние слои, блокировку, дублирование и сцены в OpenGL, Vulkan и Metal. Следование области модели не прикрепляет предмет к сетке. GIF использует первый кадр; до 16 предметов у основного питомца. См. [Плагин предметов](items-plugin.md). `BONGO_CAT_BUILD_ITEMS=OFF` исключает библиотеку.

Приоритет памяти рендеринга: Предпочитать видеопамять / Предпочитать системную память. Только Live2D Vulkan. Изменение перезагружает рендеринг. Видеопамять обеспечивает скорость; системная память снижает нагрузку на VRAM, но может работать медленнее. Для несовместимых ресурсов выбирается доступный вариант. Другие движки распределяют память автоматически; встроенные GPU используют общую память.

### Звуки клавиатуры

Включите звуковые эффекты в Плагинах. Щёлкните по клавише для выбора аудио, наведите курсор для просмотра имени и нажмите физическую клавишу для воспроизведения. Назначения сохраняются автоматически. Звуки и предметы используют отдельные потоки. WAV/MP3/Ogg Vorbis/FLAC у основного питомца. См. [Звуковые эффекты](sounds-plugin.md); `BONGO_CAT_BUILD_SOUNDS=OFF` исключает библиотеку.

Магазин Rust показывает превью, ссылки авторов и кнопки загрузки/удаления. SHA-256 проверяется перед установкой; до публикации каталога отображается заглушка. [Плагин магазина](store-plugin.md).

Автоматическая проверка обновлений включена по умолчанию в Настройки → Приложение и выполняется один раз в фоне при каждом запуске. Уведомление о новой версии сохраняется до открытия настроек и содержит кнопку «Обновить сейчас» справа вверху. Все уведомления в настройках можно закрыть вручную.

Страница моделей объединяет режимы одного пакета в карточку с выбором режима, включая стандартный режим, клавиатуру и геймпад встроенных моделей. Несколько ZIP можно перетащить для фонового импорта. Закрытие настроек не прерывает импорт. При выходе новые импорты останавливаются, а текущий источник обрабатывается до освобождения потоков и временных ресурсов.

Сочетания клавиш находятся внутри настроек: откройте Настройки и выберите Настройки / Сочетания клавиш. Магазин находится в разделе Модель через Локальные модели / Магазин. Отдельные пункты боковой панели удалены; положение прокрутки каждой подстраницы сохраняется.

При включении Live2D без Cubism Core показываются оба официальных соглашения. В Windows Согласиться и скачать загружает Native R5 SDK по официальному HTTPS, извлекает только совместимый динамический Core и включает локальный рендеринг. Отменить и продолжить оставляет плагин включённым без рендеринга. Доступны повторная загрузка и ручной импорт. Приложение и пакеты не содержат SDK или Core.

В Windows с графикой AMD доступен экспериментальный вывод DirectComposition, по умолчанию выключенный. Альфа-композиция DXGI применяется сразу, ограничивает события expose интервалом 50 мс и отключает VSync; при сбое восстанавливается прежний вывод. Чтение пикселей сохраняется; Independent Flip в играх не гарантируется.

ABI плагинов рендеринга обновлён до v2: обновляйте или пересобирайте приложение и плагины Live2D/Inox2D вместе; старые плагины несовместимы. Live2D Vulkan поддерживает выделение внеэкранных ресурсов по необходимости, потоковое масштабирование PNG на Rust и кэш BC7 с резервным RGBA8. Ограничения платформ описаны в [документации рендеринга](live2d-vulkan-metal.md).
